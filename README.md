# Unbanner rules feed

Data file used by the **Unbanner for Safari** extension to stay up to date when websites change their “Open in App” prompts.

- `v1/rules.json` — text patterns, CSS selectors, domains and paths. Data only; no code.
- Published with GitHub Pages: `https://kevenyli.github.io/unbanner-rules/v1/rules.json`
- Generated automatically. Please don’t open issues here — use [unbanner-support](https://github.com/kevenYLi/unbanner-support) instead.
